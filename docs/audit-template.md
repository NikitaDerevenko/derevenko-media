# Шаблон бесплатного разбора (для себя)

Срок — 24 часа в рабочие дни. Итог клиенту: **5–7 конкретных ошибок**, **что исправить первым**, **примерный бюджет и сроки**.
Проверяем только то, что прислали (карточка / реклама / сайт), остальное — 1–2 строки «заодно заметил».

---

## 1. Карточка на Яндекс Картах / профиль в Google

**Основное**
- [ ] Название без лишних слов, совпадает с вывеской
- [ ] Основная категория выбрана точно, дополнительные — без «мусора»
- [ ] Адрес, вход, этаж, ориентиры; метка стоит на правильном здании
- [ ] Часы работы актуальны, включая праздники
- [ ] Телефон, сайт, мессенджеры работают и кликабельны

**Контент**
- [ ] Описание отвечает «почему к вам»: ключевые услуги, район, отличия
- [ ] Меню / прайс заполнены, с ценами и фото
- [ ] Фото: обложка, вход, интерьер, продукт; светлые, без бликов, единый стиль
- [ ] Истории / публикации обновлялись за последний месяц
- [ ] Особенности: Wi-Fi, парковка, оплата картой, доставка, онлайн-запись

**Отзывы и рейтинг**
- [ ] Ответы на отзывы есть, особенно на негативные; ответы не шаблонные
- [ ] Свежие отзывы за последние 30 дней; есть ли просьба оставить отзыв
- [ ] Рейтинг и число отзывов против 3 ближайших конкурентов

**Сравнение с конкурентами** — 3 карточки рядом: фото, рейтинг, отзывы, полнота.

## 2. Реклама (Яндекс Директ / VK Реклама / Google Ads)

**Структура и настройки**
- [ ] Кампании разделены по целям / услугам / гео
- [ ] Гео: радиус или районы соответствуют реальной зоне клиентов
- [ ] Расписание показов совпадает с часами, когда отвечают на заявки
- [ ] Стратегия ставок соответствует объёму данных (нет оптимизации по конверсиям без конверсий)

**Запросы и аудитории**
- [ ] Минус-слова / исключения: нет мусорных запросов в отчёте
- [ ] Аудитории VK не слишком широкие и не пересекаются
- [ ] Нет показов на нерелевантных площадках (РСЯ, сети) без контроля

**Объявления**
- [ ] В заголовке — услуга и выгода, есть цена или оффер
- [ ] Быстрые ссылки, уточнения, адрес / визитка заполнены
- [ ] Минимум 2–3 варианта объявлений на группу для теста

**Аналитика**
- [ ] Метрика / GA4 установлена, цели (форма, звонок, мессенджер) работают
- [ ] UTM-метки на всех объявлениях
- [ ] Видна цена заявки, а не только цена клика

## 3. Сайт / лендинг

**Первый экран**
- [ ] За 5 секунд понятно: что делаете, для кого, где, что нажать
- [ ] Кнопка действия видна без прокрутки, в том числе на телефоне

**Доверие и содержание**
- [ ] Цены или «от», состав услуг
- [ ] Примеры работ, отзывы, фото настоящего места и сотрудников
- [ ] Ответы на частые вопросы и возражения

**Заявка**
- [ ] Форма не длиннее 3 полей, есть мессенджеры и телефон
- [ ] Заявка реально доходит (тестовая отправка)
- [ ] Ответ после отправки: что будет дальше

**Техника**
- [ ] Скорость на телефоне (PageSpeed mobile), вес картинок
- [ ] Адаптив: нет горизонтальной прокрутки, читаемые шрифты
- [ ] Title / description, счётчик аналитики, HTTPS

## Шаблон ответа клиенту

> Здравствуйте! Посмотрел вашу {карточку / рекламу / сайт}.
>
> **Главное, что теряет клиентов:**
> 1. …
> 2. …
> 3. …
> 4. …
> 5. …
>
> **Что исправить в первую очередь:** … (1–2 пункта, которые дадут эффект быстрее всего)
>
> **Если захотите работать вместе:** ориентир — {пакет / услуги}, от {сумма}, срок {N} дней. Рекламный бюджет — от {сумма} в месяц напрямую в рекламную систему.
>
> Могу ответить на вопросы здесь или созвониться на 15 минут.
