# Функция приёма заявок (Яндекс Облако)

Сайт — статичные файлы на GitHub Pages. Формы отправляют заявку в эту функцию, а она:
1. проверяет согласие на обработку ПД, отсеивает спам и ограничивает частоту заявок;
2. сохраняет копию заявки в бакет Object Storage — первичная запись данных граждан РФ в России (152-ФЗ);
3. присылает уведомление в Telegram.

## Как развернуть (один раз)

1. **Бакет для копий заявок.** Консоль Яндекс Облака → Object Storage → Создать бакет.
   Имя, например `derevenko-leads`, доступ на чтение и к списку объектов — **ограниченный**.
2. **Сервисный аккаунт.** IAM → Сервисные аккаунты → Создать, например `lead-function`,
   роль `storage.uploader`.
3. **Функция.** Cloud Functions → Создать функцию `lead` → Редактор → среда **Node.js 22**,
   способ — «Редактор кода», файл `index.js` — вставить содержимое `cloud/lead/index.js`.
   Точка входа: `index.handler`. Таймаут 10 с, память 128 МБ.
   Сервисный аккаунт — `lead-function`.
   Переменные окружения:
   - `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather (новый, после `/revoke`);
   - `TELEGRAM_CHAT_ID` — id чата для заявок;
   - `LEADS_BUCKET` — имя бакета из шага 1;
   - `ALLOWED_ORIGINS` — `https://derevenko-media.ru,https://www.derevenko-media.ru`.
4. **Публичный доступ.** В обзоре функции включить «Публичная функция».
   Скопировать ссылку вида `https://functions.yandexcloud.net/d4e…`.
5. **Сайт.** Вписать ссылку в `.env.production` → `NEXT_PUBLIC_LEAD_URL=…`, закоммитить в `main` —
   GitHub Pages пересоберёт сайт сам.

## Проверка

Отправить заявку с сайта: в Telegram приходит сообщение, в бакете появляется файл
`leads/ГГГГ-ММ-ДД/….json`. Если копия не сохранилась, в сообщении будет предупреждение.

Бесплатного лимита Cloud Functions (1 млн вызовов в месяц) и Object Storage хватает с большим запасом.
